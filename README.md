# 🌙 삼신이 사주풀이 (samsin-saju)

> 정해진 만세력 계산을 바탕으로 전통 명리를 쉽게 설명하고, 오늘부터 시험해볼 행동까지 정리해 주는 ChatGPT·Codex·Claude 플러그인입니다.
> 삼신이의 다정한 할머니 느낌은 은은하게 남기고, 겁주거나 운명을 단정하지 않습니다.

---

## 삼신이는 이렇게 풀이합니다

삼신이는 어려운 명리 용어를 오늘의 생활 언어로 풀어주는 다정한 할머니 안내자입니다. 평소 문장은 자연스러운 현대어로 쓰고, `~구나`, `~해보렴` 같은 어미는 핵심 조언에만 가볍게 섞습니다. 과한 애칭이나 옛말, 반복되는 비유로 고객을 유아화하지 않습니다.

삼신이의 풀이는 두 층으로 동작해요.

1. **만세력 엔진 (결정론 산출)** — 생년월일·생시·성별을 받아 사주팔자·오행·십신·십이운성·대운·세운·신살을 *계산*합니다. 같은 입력이면 항상 같은 결과예요.
2. **삼신이 해석** — 산출 카드의 값만 계산 근거로 사용하고, 이를 전통 명리 관점의 참고 해석으로 풀어냅니다. 계산값과 해석을 사실처럼 섞지 않습니다.

결과는 `한눈에 보는 핵심 → 계산 근거와 쉬운 풀이 → 생활 장면 → 오늘·이번 주 실행 카드 → 확인 기준` 순서로 제공합니다. 생년 정보만으로 완결된 풀이를 받을 수 있고, 현재 고민을 함께 말하면 그 부분에 맞춰 생활 예시를 더 좁혀 설명합니다.

사주는 **무엇을 관찰하고 조심할지** 정하고, 선택 입력인 성향 정보는 **그 행동을 어떤 방식으로 해야 옮기기 편한지** 조정합니다. 예를 들어 같은 대화 습관도 혼자 정리하는 편이면 `메모 3줄부터`, 말하며 정리하는 편이면 `10분 대화 뒤 결론 1줄`처럼 제안합니다. 성향을 제공하지 않아도 사주 풀이는 완결됩니다.

## 지원 환경과 준비

본격적으로 설치하기 전에 아래 세 가지만 확인해 주세요.

- **실행 환경** — 같은 핵심 스킬을 ChatGPT 웹·데스크톱과 승인된 모바일 플러그인, Codex CLI, Claude 데스크톱 앱·Claude Code에서 사용할 수 있습니다. Codex IDE 확장 프로그램은 플러그인 설치를 지원하지 않습니다. 호스트별 서브에이전트나 입력 위젯이 없어도 핵심 풀이 계약은 같습니다.
- **공개 레포** — 삼신이는 `davidchoi0313/samsin-saju` GitHub 공개 레포로 배포됩니다. 마켓플레이스가 동기화되려면 레포가 공개 상태여야 합니다.
- **만세력 엔진(Python)** — 풀이의 1층 엔진은 검증된 `lunar-python v1.4.8` 소스를 플러그인 안에 포함해 씁니다. 별도 `pip install`이나 런타임 인터넷 연결이 필요하지 않아 모바일·샌드박스 환경에서도 같은 계산 기준을 사용합니다.

설치 뒤 별도의 Python 패키지 준비 단계는 없습니다. 업스트림 소스와 MIT 라이선스, 버전·커밋 정보는 `scripts/vendor/lunar-python-1.4.8`에 함께 보관합니다.

## ChatGPT와 Codex에서 설치하기

이 레포에는 OpenAI용 `.codex-plugin/plugin.json`, 저장소 마켓플레이스, 스킬 UI 메타데이터가 함께 들어 있습니다. Claude용 프롬프트를 복제하지 않고 `plugins/samsin-saju/skills/saju-reading`의 같은 스킬을 양쪽에서 사용합니다.

### 방법 A — 플러그인으로 설치 (권장)

Codex CLI에서 마켓플레이스를 한 번 추가합니다.

```text
codex plugin marketplace add davidchoi0313/samsin-saju
```

그다음 ChatGPT 데스크톱 앱의 **Plugins Directory**에서 소스를 **삼신이 사주풀이**로 바꾸고 `samsin-saju`를 설치합니다. 설치 후 ChatGPT에서는 `@saju-reading`, Codex에서는 `$saju-reading`을 선택하거나 평소 말로 `사주 봐줘`라고 요청할 수 있습니다.

### 방법 B — 스킬만 설치

플러그인 목록이 필요하지 않은 Codex 로컬 사용자는 대화에서 `$skill-installer`를 선택하고 아래처럼 요청할 수 있습니다.

```text
Install the skill from https://github.com/davidchoi0313/samsin-saju/tree/main/plugins/samsin-saju/skills/saju-reading
```

기존 Claude 설정을 이미 쓰고 있다면 ChatGPT 데스크톱 앱의 **Settings → Import**에서 Claude Code 또는 Claude Cowork의 스킬·플러그인을 가져오는 방법도 사용할 수 있습니다.

### 사용 확인

```text
$saju-reading을 사용해서 1990년 3월 15일 양력, 오전 6시, 남성 기준 평생사주를 봐줘.
```

ChatGPT에서는 `$` 대신 스킬 선택기에서 **삼신이 사주풀이**를 고르거나 `@saju-reading`을 사용합니다. 필요한 정보가 모이면 별도의 현실 고민을 요구하지 않고 완성된 풀이를 제공합니다.

- [OpenAI 공식 스킬 만들기·설치 안내](https://developers.openai.com/codex/build-skills)
- [OpenAI 공식 플러그인 패키징 안내](https://developers.openai.com/plugins/build/plugins)

## ChatGPT 모바일에서 설치하기

모바일 앱에서는 GitHub 레포 주소를 직접 추가하지 않습니다. 계정에 공개되었거나 워크스페이스가 제공한 플러그인을 **Plugins** 탭에서 설치합니다.

### 같은 워크스페이스에서 바로 쓰기

1. 관리자가 데스크톱 또는 Codex CLI에서 이 레포 마켓플레이스를 추가하고 ChatGPT 데스크톱에서 `samsin-saju`를 설치합니다.
2. 워크스페이스 관리자가 https://chatgpt.com/plugins 의 **Personal** 탭에서 플러그인 `…` 메뉴를 열어 **Publish**를 누르고 접근 역할을 지정합니다.
3. 사용자는 같은 워크스페이스로 모바일 앱에 로그인하고 **Plugins** 탭에서 **삼신이 사주풀이**를 설치합니다.
4. 새 Chat 또는 Work 대화에서 `사주 봐줘`라고 요청합니다.

이 방법은 조직 내부 사용자에게 가장 빠른 배포 경로입니다. 워크스페이스 밖의 고객에게는 보이지 않습니다.

### 모든 고객에게 공개하기

일반 고객이 모바일 Plugins 탭에서 검색해 설치하려면 OpenAI Universal Plugins Directory의 검토와 승인이 필요합니다. 공개 제출용 ZIP 빌더, 등록 문구, 긍정 테스트 5개·부정 테스트 3개, 개인정보 처리방침과 약관은 [`openai-submission`](./openai-submission/)에 준비되어 있습니다. 승인 뒤 게시자가 Portal에서 **Publish**해야 실제 공개 목록에 나타납니다.

- [OpenAI 모바일 플러그인 안내](https://learn.chatgpt.com/docs/plugins)
- [OpenAI 공개 제출 안내](https://developers.openai.com/plugins/deploy/submission)

## 윈도우(및 맥) Claude 데스크톱 앱에서 설치하기

삼신이는 **데스크톱 앱의 화면(GUI)에서 메뉴를 눌러** 설치합니다. 터미널에 명령어를 칠 필요가 없어요. 아래 순서대로 따라 하면 됩니다.

> 아래 메뉴 명칭·경로는 Claude 공식 안내(Help Center, "Use plugins in Claude")를 기준으로 적었습니다. 앱 버전·언어 설정에 따라 화면의 실제 글자가 조금 다를 수 있으니, 같은 위치의 메뉴를 찾아 누르시면 됩니다.

### (a) 마켓플레이스 추가

1. 데스크톱 앱 왼쪽 사이드바에서 **Customize(커스터마이즈)** 메뉴를 엽니다. (Cowork에서 쓸 거라면 먼저 **Cowork** 탭을 연 뒤 Customize를 엽니다.)
2. **Plugins(플러그인)** 탭으로 이동합니다.
3. **Personal plugins(개인 플러그인)** 섹션에서 **`+` 버튼**을 누르고 **"Add marketplace(마켓플레이스 추가)"** 를 고릅니다.
4. **"Add from a repository(레포지토리에서 추가)"** 를 골라 GitHub 공개 레포를 동기화합니다. 레포 주소는 아래 형태예요.

```
https://github.com/davidchoi0313/samsin-saju
```

이 주소를 등록하면 삼신이 플러그인이 들어 있는 마켓플레이스가 데스크톱 앱에 추가됩니다.

> 입력 칸이 짧은 형태를 요구하면 `davidchoi0313/samsin-saju`를 입력하세요.

### (b) 플러그인 설치

1. 같은 **Customize → Plugins** 화면에서 **"Browse plugins(플러그인 둘러보기)"** 를 누릅니다.
2. 목록에서 **`samsin-saju`** 를 찾아 **"Install(설치)"** 을 누릅니다.

방금 등록한 마켓플레이스에서 삼신이 플러그인이 설치됩니다.

### (c) 설치 확인 — 삼신이가 잘 왔는지 보기

설치가 끝났는지 확인하는 방법은 두 가지예요.

- **목록으로 확인** — Customize → Plugins 화면의 설치된 플러그인 목록에 **`samsin-saju`** 가 보이고 켜져(enabled) 있으면 설치된 상태입니다.
- **불러서 확인** — Cowork(또는 Chat) 대화창에 **"사주 봐줘"** 라고 입력해 보세요. 삼신이가 필요한 정보와 보고 싶은 메뉴를 안내하면 정상 동작하는 것입니다.

> 만세력 계산 소스가 플러그인에 함께 들어 있으므로 설치 직후에도 별도 패키지 다운로드 없이 풀이를 시작할 수 있어요.

<details>
<summary><b>개발자용 참고 — 터미널 Claude Code에서 설치하기</b></summary>

데스크톱 앱이 아니라 터미널 **Claude Code**를 쓰는 개발자라면, 슬래시 명령으로도 설치할 수 있습니다. (일반 사용자는 위 데스크톱 앱 절차만 따르면 됩니다.)

```
/plugin marketplace add davidchoi0313/samsin-saju
/plugin install samsin-saju@samsin-saju-marketplace
```

설치 확인은 `/plugin` 목록에서 `samsin-saju` 가 보이는지로 합니다.

## 사용법 — 삼신이를 부르는 법

설치가 끝나면 따로 명령어를 외울 필요 없이 **Cowork(또는 Chat) 대화창에 그냥 말 걸듯이 입력하면** 됩니다. 아래처럼요.

```
사주 봐줘
```

```
1990년 3월 5일 오전 7시 남자 평생사주 봐줘
```

```
올해 운세 알려줘
```

```
나랑 1988년생 토끼띠 궁합 봐줘
```

```
오늘의 운세 어때
```

삼신이는 풀이를 하려면 **생년월일·생시·계산상 성별·음양력(양력/음력)** 이 필요합니다. 처음에 다 말하지 않아도 괜찮아요. 빠진 정보는 여러 번 끊어 묻지 않고 한 메시지에 모아 안내합니다. 생시를 모르면 `모름`이라고 답해도 되며, 시주에 기대는 부분만 제외하고 풀이합니다.

> 메뉴를 콕 집지 않고 "사주 봐줘"라고만 해도 됩니다. 삼신이가 어떤 부분이 궁금한지 한 번 확인하고, 전체적인 풀이를 원하면 **평생사주**로 안내합니다.

## 문제 해결 (FAQ)

**Q. 마켓플레이스 추가가 안 돼요 / 레포를 못 찾는대요.**
A. 레포가 공개 상태인지, 주소가 `https://github.com/davidchoi0313/samsin-saju`로 정확한지 확인해 주세요. 입력 칸이 짧은 형식을 요구하면 `davidchoi0313/samsin-saju`를 사용하세요.

**Q. 설치는 됐는데 "사주 봐줘" 해도 삼신이가 안 나와요.**
A. **Customize → Plugins** 목록에 `samsin-saju` 가 **설치됨(enabled)** 으로 보이는지 먼저 확인해 주세요. 목록엔 있는데 꺼져 있다면 켜 주시고, 그래도 안 뜨면 데스크톱 앱을 한 번 재시작한 뒤 Cowork(또는 Chat) 대화창에서 다시 불러 보세요. (서브에이전트 등 일부 기능은 Cowork에서만 동작하니, 안 보이면 Cowork 탭에서 시도해 보시는 것도 방법이에요.)

**Q. 첫 풀이가 멈추거나 오류가 나요 / "만세력에 먼지가 끼었다"고 해요.**
A. 만세력 엔진은 플러그인에 포함되어 있어 패키지를 따로 설치할 필요가 없습니다. 플러그인을 최신 버전으로 다시 설치한 뒤 같은 입력으로 재시도해 주세요. 그래도 실패하면 오류 문구와 사용 환경을 문의처로 보내 주세요. 엔진이 실행되지 않으면 삼신이는 계산 결과를 지어내지 않습니다.

**Q. 풀이 문장이 매번 조금씩 달라져요.**
A. 같은 생년월일·생시·성별·음양력을 넣었다면 사주팔자·오행·대운 같은 **계산값은 같아야** 정상입니다. 다만 이를 설명하는 문장과 생활 예시는 조금 달라질 수 있습니다. 계산 기준이 달라 보인다면 입력값, 특히 양력·음력과 생시를 다시 확인해 주세요.

## 결과에서 받게 되는 것

각 결과는 긴 설명만 늘어놓지 않고 아래 질문에 답하도록 설계되어 있습니다.

1. 내 계산 결과에서 가장 눈에 띄는 강점과 주의점은 무엇인가?
2. 왜 그렇게 읽었으며, 어디까지가 계산이고 어디부터가 전통 해석인가?
3. 일·관계·생활에서는 어떤 장면으로 나타날 수 있는가?
4. 오늘 10분, 이번 주 한 번 무엇을 더 해보고 무엇을 조심할 것인가?
5. 7일 뒤 무엇을 보고 계속할지, 바꿀지, 그만둘지 판단할 것인가?

행동 제안에는 시작 시점, 관찰 가능한 행동, 끝낼 수 있는 분량, 완료 기준을 함께 넣습니다. 행운을 보장하는 처방이 아니라 자신에게 맞는지 안전하게 확인하는 작은 실험입니다. 어떤 행동을 선택할지는 고객에게 있으며, 실제 도움이 없거나 부담이 커지면 수정하거나 중단하도록 안내합니다.
