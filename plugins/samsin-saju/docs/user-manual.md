# 삼신이 사주풀이 사용 매뉴얼

삼신이는 정해진 만세력 계산을 바탕으로 전통 명리를 쉽게 설명하고, 생활에서 시험해볼 작은 행동까지 정리해 주는 ChatGPT·Codex·Claude 플러그인입니다. 실제 풀이는 다정한 할머니 느낌의 반말로 전달하지만, 과한 애칭이나 낯선 옛말을 반복하지 않습니다.

## 1. 무엇을 제공하나요?

삼신이의 풀이는 두 단계를 거칩니다.

1. **만세력 계산** — 생년월일·생시·음양력·계산상 성별을 바탕으로 사주팔자, 오행, 십신, 대운 등을 정해진 방식으로 계산합니다. 같은 입력이면 계산값도 같습니다.
2. **전통 명리 해석** — 계산 카드에 실제 있는 값만 근거로 쉬운 설명과 생활 예시를 만듭니다. 이 부분은 전통적 해석이며 과학적 사실이나 미래 예언이 아닙니다.

결과는 보통 아래 순서로 나옵니다.

- 한눈에 보는 강점·주의점·첫 행동
- 왜 그렇게 읽었는지 보여주는 계산 근거와 쉬운 풀이
- 일·관계·생활에서 나타날 수 있는 구체적인 장면
- 오늘 10분과 이번 주 한 번 해볼 실행 카드
- 7일 뒤 유지·수정·중단을 판단할 확인 기준

현재 고민을 따로 말하지 않아도 생년 정보만으로 완결된 풀이를 제공합니다. 고민이나 목표를 함께 말하면 그 부분에 맞춰 예시와 행동을 더 좁혀 설명합니다.

사주는 무엇을 관찰하고 조심할지 정하고, 선택 입력인 성향 정보는 그 행동을 글·대화·계획·선택지 중 어떤 방식으로 실행하면 편할지 조정합니다. 성향은 사주 계산의 근거가 아니며, 제공하지 않아도 풀이의 깊이나 실행성은 낮아지지 않습니다.

## 2. 설치 방법

같은 사주 스킬을 ChatGPT·Codex와 Claude에서 사용할 수 있습니다. 앱 버전이나 언어 설정에 따라 메뉴 이름은 조금 다를 수 있습니다.

### ChatGPT·Codex

Codex CLI에서 저장소 마켓플레이스를 추가합니다.

```text
codex plugin marketplace add davidchoi0313/samsin-saju
```

ChatGPT 데스크톱 앱의 **Plugins Directory**에서 **삼신이 사주풀이** 소스를 고르고 `samsin-saju`를 설치합니다. ChatGPT에서는 `@saju-reading`, Codex에서는 `$saju-reading`으로 직접 선택할 수 있으며, 스킬 이름을 쓰지 않고 `사주 봐줘`라고 요청해도 자동으로 선택될 수 있습니다.

플러그인 대신 스킬 하나만 설치하려면 Codex에서 `$skill-installer`를 선택하고 아래 GitHub 경로를 설치해 달라고 요청하세요.

```text
https://github.com/davidchoi0313/samsin-saju/tree/main/plugins/samsin-saju/skills/saju-reading
```

기존 Claude 설정을 이미 사용 중이라면 ChatGPT 데스크톱 앱의 **Settings → Import**에서 Claude Code 또는 Claude Cowork 설정을 가져올 수도 있습니다.

### Claude 데스크톱 앱

1. **Customize → Plugins**를 엽니다.
2. **Personal plugins**에서 **Add marketplace**를 선택합니다.
3. 아래 공개 레포 주소를 입력합니다.

```text
https://github.com/davidchoi0313/samsin-saju
```

4. 플러그인 목록에서 `samsin-saju`를 찾아 설치하고 활성화합니다.
5. 새 대화에서 `사주 봐줘`라고 입력해 설치 여부를 확인합니다.

Claude Code에서는 다음 명령을 사용할 수 있습니다.

```text
/plugin marketplace add davidchoi0313/samsin-saju
/plugin install samsin-saju@samsin-saju-marketplace
```

설치 뒤 따로 준비할 것은 없습니다. 만세력 계산에 쓰는 `lunar-python v1.4.8` 소스가 플러그인 안에 함께 들어 있어, 별도 패키지 설치나 실행 중 인터넷 연결이 필요하지 않습니다.

## 3. 이렇게 요청해 보세요

명령어를 외울 필요 없이 평소 말하듯 요청하면 됩니다.

```text
1990년 3월 15일 양력, 오전 6시, 남성 기준으로 평생사주 봐줘.
```

```text
1988년 7월 20일 음력, 태어난 시간은 모르고 여성 기준이야. 올해운세 알려줘.
```

```text
두 사람 정보를 줄 테니 궁합을 생활 조언까지 포함해서 자세히 봐줘.
```

```text
오늘의 운세를 짧게 알려줘.
```

메뉴를 정하지 않고 `사주 봐줘`라고만 해도 괜찮습니다. 삼신이가 어떤 부분이 궁금한지 한 번 확인하고, 전체적인 풀이를 원하면 평생사주부터 안내합니다.

## 4. 필요한 정보

| 항목 | 설명 | 필요 여부 |
|---|---|---|
| 음양력 | 양력 또는 음력. 음력이면 평달·윤달도 확인 | 필수 |
| 생년월일 | 가능하면 `YYYY-MM-DD` 형식 | 필수 |
| 계산상 성별 | 현재 엔진의 대운 순역 계산은 남성·여성 기준을 사용 | 필수 |
| 생시 | 태어난 시간. 모르면 `모름`으로 진행 | 권장 |
| 이름 | 결과에서 불러줄 호칭으로만 사용 | 선택 |
| 성향 유형 | 이미 알고 있고 직접 제공한 경우 조언 전달법에만 참고 | 선택 |

빠진 정보는 여러 번 끊어 묻지 않고 한 메시지에 모아 안내합니다. 생시를 모르면 시주에 의존하는 해석만 제외하고 나머지 풀이를 진행합니다.

궁합과 사업 궁합은 두 사람의 정보를 구분해서 입력해야 하며, 상대방 정보를 제공할 때는 당사자의 동의를 전제로 합니다.

### 태어난 시간 기준

| 시 | 시간대 | 시 | 시간대 |
|---|---|---|---|
| 자시 | 23:30~01:30 | 오시 | 11:30~13:30 |
| 축시 | 01:30~03:30 | 미시 | 13:30~15:30 |
| 인시 | 03:30~05:30 | 신시 | 15:30~17:30 |
| 묘시 | 05:30~07:30 | 유시 | 17:30~19:30 |
| 진시 | 07:30~09:30 | 술시 | 19:30~21:30 |
| 사시 | 09:30~11:30 | 해시 | 21:30~23:30 |

태어난 시각을 **분 단위로 아신다면 그대로 알려주세요.** 위 표의 경계 근처(예: 07:30 언저리)에 태어나셨다면 진태양시 보정 때문에 실제로 갈리는 지점이 표의 시각과 다릅니다. 분 단위를 주시면 그 보정까지 반영해 계산합니다.

### 출생 지역

만세력 계산은 **대한민국 표준시(동경 135도)를 기준**으로 진태양시를 보정합니다. 해외 출생의 표준시 보정은 아직 지원하지 않습니다. 해외에서 태어나셨다면 년·월·일주는 그대로 쓰되, 태어난 시각으로 읽는 부분(시주)은 어긋날 수 있다는 점을 함께 안내해 드립니다.

## 6. 결과를 잘 읽는 법

- **계산값과 해석은 다릅니다.** 오행의 개수와 대운 구간은 계산 결과이고, 그 의미를 생활 장면으로 옮긴 문장은 전통 명리 관점의 참고 해석입니다.
- **맞지 않는 해석은 버려도 됩니다.** 고객이 실제로 겪은 경험이 해석보다 우선합니다.
- **행동 카드는 작은 실험입니다.** 운을 바꾸거나 결과를 보장하는 처방이 아니라, 해석이 내 생활에 도움이 되는지 확인하는 방법입니다. 활용할 행동·조심할 행동·확인할 행동 중 가장 부담 없는 하나부터 고르면 됩니다.
- **중요한 결정은 현실 자료가 먼저입니다.** 투자, 퇴사, 계약, 결혼, 치료, 채용 같은 결정은 사주가 대신하지 않습니다.

자주 나오는 용어는 결과 안에서 처음 등장할 때 바로 생활어로 풀어 설명합니다.

- **일간** — 사주에서 나를 나타내는 중심 글자
- **오행** — 목·화·토·금·수 다섯 요소의 분포
- **십신** — 나를 기준으로 다른 글자와 맺는 관계를 분류한 이름
- **대운** — 10년 단위로 계산되는 큰 구간
- **세운** — 특정 연도의 기운을 나타내는 계산값
- **용신** — 사주의 균형을 설명하기 위해 선택하는 규칙 기반 후보
- **신살** — 전통 명리에서 특정 조합에 붙인 상징적 이름

## 7. 안전 안내

> 본 풀이는 전통 명리학·무속에 기반한 오락·참고용이며, 의학·법률·재정적 조언이 아닙니다. 중요한 결정은 본인의 판단과 전문가의 조언에 따르시기 바랍니다.

- 건강운은 질병·장기 상태·체질을 진단하지 않으며, 음식·영양제·치료를 처방하지 않습니다. 증상이나 건강 우려가 있으면 의료 전문가와 상담하세요.
- 귀신사주·전생사주·신살풀이는 상징적 이야기입니다. 초자연적 존재, 저주, 빙의, 업보를 사실로 확인하지 않습니다.
- 궁합과 연애운은 결혼·이별·외도나 상대의 마음을 예언하지 않습니다.
- 사업 궁합은 동업·투자·계약의 가부와 수익을 판정하지 않습니다.
- 업무 협업 참고는 지원자의 합불·등급·순위·적합도를 만들지 않습니다. 실제 채용은 직무 자격과 구조화된 평가 기준이 우선입니다.
- 출생 정보는 민감할 수 있습니다. 본인과 상대방이 제공해도 괜찮다고 판단한 정보만 입력하고, 플랫폼의 데이터 처리 정책도 함께 확인하세요.

## 8. 문제 해결

### 설치했는데 삼신이가 응답하지 않아요

Claude의 **Customize → Plugins**에서 `samsin-saju`가 설치되고 활성화되어 있는지 확인한 뒤 새 대화에서 다시 시도하세요.

### 첫 풀이에서 엔진 오류가 나요

만세력 엔진은 Python과 플러그인에 함께 들어 있는 `lunar-python v1.4.8` 소스를 사용합니다. 패키지를 따로 설치할 필요는 없으므로, Python이 실행되는 환경인지 확인한 뒤 같은 입력으로 다시 요청하세요. 엔진이 실행되지 않으면 삼신이는 계산 결과를 지어내지 않습니다.

### 같은 입력인데 문장이 달라요

사주팔자·오행·대운 같은 계산값은 같아야 하지만, 설명 문장과 생활 예시는 조금 달라질 수 있습니다. 계산 기준이 달라 보인다면 양력·음력, 생시, 계산상 성별을 다시 확인하세요.
