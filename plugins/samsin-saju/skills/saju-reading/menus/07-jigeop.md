# M07. 직업운

## 목적

특정 직업을 운명처럼 지목하지 않고, 개인 카드에서 읽히는 `잘 맞을 수 있는 과제·환경·일하는 방식`을 제시한다. 고객이 실제 업무에서 검증할 수 있는 2주 실험까지 제공한다.

## 입력과 허용 필드

M01 입력을 사용한다. `dayMaster` · `fiveElements` · `tenGods` · `yongshin`만 쓴다.

`tenGods`는 위치별 값이지 수치 비중이 아니다. 카드에 없는 경력·능력·자격·수입을 추정하지 않는다.

## 십신의 쉬운 업무 번역

실제 카드에 있는 십신만 아래 범위로 번역한다.

| 십신 범주 | 업무에서 살펴볼 주제 |
|---|---|
| 비견·겁재 | 독립성, 동료와의 역할 경계, 경쟁·협업 방식 |
| 식신·상관 | 설명, 제작, 개선, 아이디어를 밖으로 꺼내는 일 |
| 정재·편재 | 자원·일정·고객·성과를 관리하는 일 |
| 정관·편관 | 기준, 책임, 품질, 규칙을 지키고 운영하는 일 |
| 정인·편인 | 학습, 조사, 해석, 문서화, 전문성을 쌓는 일 |

이 번역은 능력 보증이나 직업 적합 판정이 아니다.

## 메뉴 본문

1. **잘 맞을 수 있는 과제** — 직업명이 아니라 실제 업무 과제 3개 이내로 제시한다.
2. **힘이 살아나는 환경** — 혼자/협업, 변화/규칙, 시작/운영처럼 카드가 닿는 조건을 설명한다.
3. **강점의 반대 비용** — 강점이 과하면 생길 수 있는 업무 패턴과 조정법을 제시한다.
4. **직무 방향 선택지** — 서로 다른 방향 2~3개와 각 방향을 먼저 검증할 행동을 비교한다.
5. **2주 직무 실험** — 실제 적합성을 확인할 기록 방법을 제공한다.

## 복사해서 쓰는 2주 실험표

각 개인 카드에 맞는 과제 하나를 넣어 아래 형식으로 출력한다.

```text
시험할 과제:
두 번 실행할 날짜:
한 번에 쓸 시간:
끝나고 기록할 것: 몰입도 / 피로도 / 결과물 만족도 / 주변 반응 (각 1~5점)
계속할 기준:
그만둘 기준:
```

## 실행 설계

- 오늘 10분: 선택지 중 하나를 고르고 시험할 과제와 날짜를 적기
- 2주 동안: 같은 유형의 과제를 최소 두 번 해보기
- 종료일: 점수와 실제 결과물을 보고 확대·수정·중단 결정하기

## 권장 밀도

2,500~4,500자. 직업명 목록을 길게 나열하지 않는다.

## 안전과 면책

퇴사·이직·창업·투자 여부나 수입을 단정하지 않는다. 실제 경력·기술·노동시장·생활비 검토가 사주보다 우선임을 알린다.
